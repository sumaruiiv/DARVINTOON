# DARVIN-CHERCI — เว็บอ่านมังงะ “ดินสอสีฟ้า”

เว็บอ่านมังงะเรื่อง **“ดินสอสีฟ้า”** ครบ 8 ตอน (96 หน้า) อ่านแบบเลื่อนยาวต่อเนื่องเหมือนแอปเว็บตูน
หน้าแรกออกแบบสไตล์หน้าร้าน Apple โทนฟ้า-น้ำเงิน มีลูกเล่น

- กระเป๋าดินสอ 3D หมุนได้ ลากซิปเพื่อเปิด → ดินสอกดสีฟ้า (ทรง Pentel P207) ลอยออกมาพร้อมปกทุกตอน
- ปฏิทิน 3D สิงหาคม 2025 → มีนาคม 2026 จับปลายกระดาษแล้วลากขึ้นเพื่อพลิกเดือน มีของตกแต่งประจำเดือน
- ชั้นวางหนังสือไม้ 3D หนังสือที่เรืองแสงหยิบออกมาได้
- หน้าโหลดรูปดินสอขีดเส้นม้วนเป็นหัวใจ, เมฆลอยในธีมสว่าง, หน้าต่างโดเนท

ออกแบบและพัฒนาเว็บไซต์โดย **DVN7DAZY**

## โครงสร้าง

```
index.html          หน้าแรก
read.html           หน้าอ่าน (read.html?ep=1 ถึง ?ep=8)
assets/css/         style.css (หลัก) + features.css (ลูกเล่นใหม่)
assets/js/data.js   ข้อมูลตอน + เรื่องย่อ + ตัวละคร + วันสำคัญในปฏิทิน  ← แก้ข้อความได้ที่นี่
assets/js/          hero3d.js (กระเป๋าดินสอ), pencil3d.js, calendar.js, shelf3d.js,
                    donate.js (ข้อมูลโดเนทอยู่บนสุดของไฟล์), common.js, home.js, reader.js
assets/donate/      รูป QR พร้อมเพย์
assets/covers/      ภาพปกแต่ละตอน
manga/ep1..ep8/     หน้าการ์ตูน (WebP กว้าง 1000px)
api/visits.js       ตัวนับผู้เข้าชมบน Vercel (ทางเลือกเสริม)
```

เป็นเว็บแบบ static ไม่ต้อง build อะไร เปิดใช้ได้ทันที

## อัปขึ้น GitHub

1. สร้าง repository ใหม่ที่ https://github.com/new (ตั้งชื่อเช่น `blue-pencil-manga`)
2. ในโฟลเดอร์นี้ รันคำสั่ง (เปลี่ยน `YOUR-NAME` เป็นชื่อบัญชี GitHub)

```bash
git remote add origin https://github.com/YOUR-NAME/blue-pencil-manga.git
git push -u origin main
```

หรือจะลากไฟล์ทั้งหมดไปวางในหน้า “Upload files” ของ GitHub ก็ได้

## อัปขึ้น Vercel

1. เข้า https://vercel.com/new แล้วเลือก repository `blue-pencil-manga` จาก GitHub
2. Framework Preset เลือก **Other** ไม่ต้องตั้ง Build Command → กด **Deploy**
3. ทุกครั้งที่ push ขึ้น GitHub เว็บบน Vercel จะอัปเดตเอง

## ตัวนับผู้เข้าชม

- ค่าเริ่มต้นใช้บริการนับฟรี (abacus.jasoncameron.dev) ไม่ต้องสมัครอะไร
- นับ 1 ครั้งต่อการเข้าเว็บ 1 ครั้ง ตัวเลขนับขึ้นอย่างเดียว ไม่มีลด และอัปเดตเองทุก 30 วินาที
- ถ้าต้องการเก็บตัวเลขไว้ในบัญชีของตัวเอง: ใน Vercel ไปที่ **Storage → Create → Upstash (Redis)** แล้วเชื่อมกับโปรเจกต์
  ระบบจะเปลี่ยนไปใช้ `api/visits.js` อัตโนมัติ โดยตั้งค่าเริ่มจากตัวเลขเดิม จึงไม่ย้อนกลับเป็น 0

## ทดลองเปิดในเครื่อง

```bash
python -m http.server 5173
```

แล้วเปิด http://localhost:5173 (ตอนทดสอบในเครื่องจะใช้ตัวนับแยกไว้ ไม่ปนกับตัวเลขจริง)
